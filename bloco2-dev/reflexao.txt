# ATIVIDADE 5 — O shell como JCL moderno

# O slide da genealogia mostrou que o JCL usava comandos como
# // ASSIGN SYS004,TAPE para associar um trabalho a um dispositivo.
# No shell moderno, qual mecanismo cumpre papel equivalente?
# Dê um exemplo concreto do que você usou nesta atividade.

Resposta:
No shell moderno, isso é feito por redirecionamentos e pipes.
Eles conectam programas, arquivos e dispositivos de entrada e saída.
Um exemplo usado na atividade foi:

strace echo "ola" 2>&1 | grep write

Nesse comando, a saída de um programa foi redirecionada e enviada
para outro comando usando pipe.

# ATIVIDADE 6 — Make

# 1. O monitor histórico verificava a conclusão de cada job antes
#    de despachar o próximo. No make, qual mecanismo cumpre esse
#    papel? Como o make sabe que não precisa recompilar um arquivo
#    que não mudou?

Resposta 1:
O make usa dependências e comparação de datas dos arquivos.
Ele verifica se o arquivo fonte foi modificado depois do arquivo
executável ou objeto. Se nada mudou, o make entende que não precisa
recompilar.


# 2. O monitor unificava "supervisor, carregador e rotinas de I/O
#    sob uma interface textual". O que o Makefile unifica no fluxo
#    de desenvolvimento moderno?

Resposta 2:
O Makefile unifica tarefas de compilação, ligação, execução e limpeza
do projeto em um único arquivo de configuração. Assim, o desenvolvedor
consegue automatizar todo o fluxo de desenvolvimento usando comandos
simples no terminal.
